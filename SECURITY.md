# Security Policy

## Scope

This policy covers this repository (`theme-tapestry-dev`), which is the
source of truth for the Tapestry theme under `themes/tapestry/`, as well as
the code that gets synced out to the standalone
[`anirbanbasu/tapestry`](https://github.com/anirbanbasu/tapestry) repository
on each tagged release. Report vulnerabilities found in either repository
here.

## Supported versions

Tapestry does not maintain multiple parallel release lines. Only the latest
tagged release of the theme, and the `master` branch of this repository, are
supported with security fixes.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, use GitHub's [private vulnerability
reporting](https://github.com/anirbanbasu/theme-tapestry-dev/security/advisories/new)
for this repository (accessible via the **Security** tab → **Report a
vulnerability**). This allows the report to be discussed and fixed
privately before any public disclosure.

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce, or a minimal example site/config that triggers it.
- The affected version or commit.

## Response expectations

This is a personal/hobby project maintained on a best-effort basis. There is
no guaranteed response time or SLA, but reports will be acknowledged and
triaged as soon as reasonably possible.
